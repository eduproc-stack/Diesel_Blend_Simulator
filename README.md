# EduProc – Marin-diesel, blandningssimulator

Interaktiv undervisningssimulator för blandning av två oljeströmmar med olika svavelhalter.

## Användning
Öppna `index.html` i en webbläsare. Ingen installation eller extern JavaScript-tjänst krävs.

## Publicera på GitHub Pages
1. Skapa ett nytt GitHub-repository eller använd ett befintligt.
2. Ladda upp `index.html` till repositoryts rot (eller till `docs/`).
3. Under **Settings → Pages**, välj **Deploy from a branch**, `main`, och `/ (root)` (eller `/docs`).
4. Spara och öppna den URL GitHub visar när publiceringen är klar.

## Modellantaganden
- Totalt flöde: 10 ton/h.
- Komponent A: 2,0 mass-% svavel.
- Komponent B: 0,1 mass-% svavel.
- Produktspecifikation: högst 0,5 mass-% svavel.
- Pedagogisk säkerhetsgräns: 0,5 % minus tre standardavvikelser.
